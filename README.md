# sre-demo-2024

## Executive Summary

`sre-demo-2024` is a compact Terraform proof-of-concept for demonstrating Site Reliability Engineering (SRE) and CI/CD infrastructure workflows on AWS. The project provisions a simple public web server environment in `us-east-2`, including a custom VPC, subnet, internet gateway, route table, security groups, elastic IP, network interface, and an Ubuntu EC2 instance running Apache.

The repository is intended as a hands-on lab baseline for practicing infrastructure-as-code delivery patterns, Terraform state management, cloud networking fundamentals, and incremental operational improvements. It is deliberately small and approachable, making it suitable for demos, training, and iterative refinement of SRE practices such as change control, review, validation, deployment automation, and infrastructure hardening.

## Overview

This project functions as a Proof of Concept (POC) test environment, focusing on CI/CD methodologies and ongoing education in Site Reliability Engineering (SRE).
